一款适用于 JetBrains 系列 IDE 的插件，帮助你通过可视化界面生成符合规范的 Commit Message，并在提交前进行严格的格式校验。

### ✨ 核心功能

- 提供标准化的 UI 界面，一键生成 Commit 模板。
- 提交代码时自动校验 Commit 格式，保持代码仓库的提交记录整洁。
- 基于标准的 Angular 提交规范：
    ```text
    <type>(<scope>): <subject>
    <BLANK LINE>
    <body>
    <BLANK LINE>
    <footer>
    ```

### 📦 安装方式

1. 打开 JetBrains IDE。
2. 进入 Preferences / Settings > Plugins > Marketplace。
3. 搜索 `Git Commit Template Check` 并安装。
4. 重启 IDE 即可使用。
